# Skipper — C2 Trainer

A private study site for Mark Skipper's *Advanced Grammar & Vocabulary* (Express Publishing): 117 units, 2,998 words and phrases, spaced repetition (FSRS-6), unit tests and nine games.

- **Open it:** https://moskalikigor092-hue.github.io/skipper-trainer/
- **Access:** the word lists are encrypted (`data/book.bin`, AES-256-GCM). The site asks for an access code; ask the owner for it.
- **Progress:** stored in your browser. Use *Account → Move to another device* to carry it over.

## What's inside
- `index.html`, `assets/` — the app (plain HTML/CSS/JS, no build step)
- `data/book.bin` — encrypted book data
- `.nojekyll` — tells GitHub Pages to serve files as they are

The book's text is copyrighted; this site is for the owner's private study, which is why the content is encrypted.
